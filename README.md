# 🔍 Image Tampering Detection Using YOLOv8

A Computer Vision project designed to detect manipulated or tampered regions in images using **YOLOv8** and **Python**.

## 🎯 Project Objective

The objective of this project is to explore AI-based image forensics by training a YOLOv8 model to identify suspicious or manipulated regions in digital images.

## 🧠 Technologies Used

- Python
- YOLOv8
- Computer Vision
- Deep Learning
- Image Processing
- Object Detection

## 📁 Project Structure

| File | Purpose |
|------|---------|
| `main.py` | Main project script |
| `prepare_casia_yolo.py` | Prepares the CASIA dataset for YOLO format |
| `train_yolo.py` | YOLOv8 model training script |
| `tamper.yaml` | Dataset/training configuration |
| `yolov8n.pt` | YOLOv8 Nano pretrained model |

## ⚙️ Workflow

**Image Dataset → Data Preparation → YOLO Format → Model Training → Detection**
